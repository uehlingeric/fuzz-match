# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] — 2026-07-11

Initial release.

- Two matching algorithms: TF-IDF cosine similarity (fast, large datasets) and Levenshtein WRatio (accurate, short strings)
- CLI and Python API interfaces
- Pre-match execution time estimation
- Unicode normalization and punctuation handling
- CSV input/output support (single-list self-match or cross-list matching)
